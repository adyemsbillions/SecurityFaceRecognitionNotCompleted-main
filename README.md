# 🛡️ Security Face Recognition System (Incomplete Project)

This is an **incomplete security face recognition system** built with Python and OpenCV. It aims to detect, register, and recognize faces using webcam input — intended for access control or attendance logging systems. The codebase is a starting point for a complete face-based security solution.

> ⚠️ **Note**: This project is not yet complete. Some features are missing or require improvements.

---

## 📌 Features (Planned & Current)

- [x] Face detection using Haar Cascades
- [x] Face dataset collection by ID
- [x] Model training using LBPH (Local Binary Pattern Histogram)
- [x] Real-time face recognition via webcam
- [ ] GUI interface for management
- [ ] Attendance/Access log
- [ ] User profile integration

---

## 🧰 Requirements

- Python 3.6 or later
- OpenCV
- Numpy
